# Misalignment, mapped

An unofficial explainer of the public evidence that AI models pursue goals other than the ones their developers meant (reward hacking, sleeper agents, alignment faking, scheming, sandbagging) and of how labs test for it. Fifteen parts, each built from primary sources published 2019 to 2026.

Live: https://idvorkin-ai-tools.github.io/misalignment-field-map/

Static HTML; `paper.css` is shared by every page and `nav.js` holds the page selector. Pages explain in their own words and link to the source, with short cited quotes only. Term boxes and the Plain / Technical / ELI5 switch come from the shared `assets/terms.js` on [the org site](https://idvorkin-ai-tools.github.io/safety.html).
